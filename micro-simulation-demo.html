Microlearning & Technology Enablement Demo

Rapid Software Simulation Development

Here’s a quick overview of how I used generative AI to develop a custom microlearning app with an interactive walkthrough and three scenario-based simulations, which can be embedded or served independently. Check out the demo below!

About this Project

Fifteen years ago, when I started developing blended learning experiences for complex technical configurations and administrator onboarding, I loved using tools like Captivate and Articulate to make interactive software simulations. This was a low-stakes way for learners to see the tool in action and actually get their hands on it without risking any real-world consequences.

Developing these simulations was time-consuming at first, but nevertheless rewarding. Maintenance, on the other hand, was often time consuming, and both editing and creation stayed with one or two people because of high licensing costs and steep learning curves.

For this project, I wanted to see if I could use generative AI to create a similar simulation experience with lower overhead.

The Challenge

Create a custom microlearning simulation at a fraction of the cost without sacrificing quality or interactivity. The LX must include an instructional and evaluation element.

Hypothesis: Build a vibe coded HTML software simulation on par with past Captivate projects, including an interactive walkthrough and knowledge simulator.

The Solution

A mobile-first micro-enablement application that can be served on its own or embedded in other e-learning projects, such as an Articulate Rise course using a Custom HTML block.

Next Step: Build an automated workflow with an intelligent intake parser, flexible module templates, and multi-step SDLC to develop prototypes, facilitate human testing, and deploy solutions in minutes.

Check Out the Mobile-First Experience

This demo is a lightweight standalone HTML application that can be embedded on an intranet page, in an e-learning course, or even within an app's help files. The simulation is designed to be mobile-first, so users can also access it directly for a more native experience.
