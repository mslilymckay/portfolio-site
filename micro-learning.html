Acme Flux AI Coach

Lightweight game-based micro-learning app optimized to increase AI fluency without every touching an AI model.

About this Project

Several friends and colleagues are still reluctant to try AI, often because they don't feel confident with the basic concepts. So I built a micro-learning prototype (deployed as a Progressive Web App) called Acme Flux AI Coach to help bridge that gap.

This is a partial prototype to demonstrate how learners can grasp high-level AI concepts without every touching a prompt box. It relies on concepts like micro interactions and real-time gamification to engage learners in their own time.

Through this process I jumped to the next level of vibe coding by expanding to a React/Vite architecture, experimenting with advanced interactions, and continuing to use Antigravity to automate local SDLC workflows to audit code, implement complex features, and deploy to production.

Requirements

A quick, fun game-based micro-learning POC to teach foundational AI concepts. Must include five progressive levels of application, gamified elements, and offline caching.

The Solution

A React/Vite PWA that can be installed on any device for a native app experience without the overhead of a traditional mobile app or SCORM module. This POC demo includes three interaction types: drag-and-drop matching, red pen strike-through, and resource selection.
Note: This is a partial prototype demonstrating the learner journey from solving cases and unlocking their resources to earning XP and a badge for completing Level 2.

Install the Demo on Your Device

This prototype is built as a Progressive Web App (PWA). Access the link directly on your phone and tap Add to Home Screen to install it for a full screen native app experience.

Note: This is a demo-only version of the app. All changes you make will only save locally. Contact me directly if you want to sign up for a fully-functional version.
