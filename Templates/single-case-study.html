Case Study Title

Using generative AI to develop custom microlearning apps with interactive walkthroughs and scenario-based simulations.

About this Project

When I used to develop blended learning experiences for complex technical configurations and administrator onboarding, I loved using tools like Captivate and Articulate to make interactive software simulations. This was a low-stakes way for learners to see the tool in action and actually get their hands on it without risking any real-world consequences. Developing these simulations was time-consuming at first, but nevertheless delightful. Maintenance, on the other hand, was perpetually time consuming, not to mention editing and creation usally stayed with one or two people based on both licensing costs and steep learning curves. For this project, I wanted to see if I could use generative AI to create a similar simulation experience with lower overhead.

The Challenge

Software simulations can be invaluable for learning, but they are often expensive to create and maintain. We needed a way to create custom microlearning simulations at a fraction of the cost without sacrificing quality or interactivity.

The Solution

A mobile-first micro-enablement application that can be served on its own or embedded in other e-learning projects, such as an Articulate Rise course using the Custom HTML feature.
